# Frontend UI Components

The `web/components/ui/` directory provides headless & styled foundation primitives:

- **`Button`**: Primary, secondary, danger, outline, and ghost variants with integrated loading states.
- **`Input`**: Standardized text, password, and email input field with label and error rendering.
- **`Select`**: Dropdown select input.
- **`Modal`**: Accessible dialog overlay supporting backdrop dismissal and keyboard escape shortcuts.
- **`Table`**: Generic type-safe data table with custom column renderers.
- **`Pagination`**: Pagination controls rendering page ranges and next/previous controls.
- **`Loading`**: Animated loading spinner.
- **`EmptyState`**: Empty data list placeholder.
- **`ErrorState`**: Styled error card with optional retry button.
